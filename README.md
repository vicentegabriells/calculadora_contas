# Calculadora de Gastos

> Já pensou em uma calculadora de gastos que você anexasse diversos comprovantes e os mesmo fossem lidos e gerado um calculo total de gastos? É exatamente isso que este pequeno projeto web faz.

> URL para acessar no navegador: https://vicentegabriells.github.io/calculadora_contas/

## Tecnologias Utilizadas

Liste as linguagens, frameworks, bancos de dados e ferramentas principais que compõem o projeto.

*   **HTML5 e CSS3**
*   **JavaScript (ES6+)**
*   **Puter.js (API de IA para leitura e chat)**
*   **Font Awesome (Ícones)**

## Pré-requisitos

Antes de começar, você vai precisar ter as seguintes ferramentas instaladas na sua máquina:

*   LiveServer (Extensão do VS Code ou similar)

## Instalação e Configuração

Siga os passos abaixo para configurar o ambiente de desenvolvimento local.

1. Abra o Terminal do seu computador.
2. Navegue até a pasta onde deseja clonar este repositório. \
   Exemplo:
   ```bash
   cd Documentos/Projetos/clonados_do_github
3. Clone este repositório:
   ```bash
   git clone https://github.com/vicentegabriells/calculadora_contas.git
   ```
4. Entre no repositório:
   ```bash
   cd calculadora_contas
5. Abra na sua IDE de preferencia:\
   ```bash
   code .
   ```
   Ou no seu explorador, navegue até o repositório e escolha em abrir com a IDE de sua preferencia.
   
6. Dentro do arquivo **index.html**, aperte no botão direito do mouse e escolha a opção "Abrir com LiveServer".
